### 🚀 正在维护与折腾的项目

- 🎬 **[VideoAgent](https://github.com/ciyuan1234/VideoAgent)**  
  面向 Apple Silicon 的开源自动化科技视频工坊。告别繁琐的手工剪辑和逐帧对轴，写好声明式 YAML 剧本，即可全自动完成 32kHz 录音棚语音合成、Silicon 语法高亮代码卡片、Mermaid 架构流程图渲染与 1080P/60FPS 成片交付。

- 🤖 **[MCM_skills](https://github.com/ciyuan1234/MCM_skills)**  
  专为全国大学生数学建模竞赛（CUMCM）与美赛（MCM）设计的 AI Skill 工具包。将审题拆解、数据契约规范、机理/PDE 建模推导到论文撰写的流程标准化，适配 Claude Code 与各类 Agent 终端。

- 📊 **[MCM_2026](https://github.com/ciyuan1234/MCM_2026)**  
  数学建模竞赛的开源实战沉淀库。收录论文初稿、FVM 偏微分方程仿真源码、结果数据契约与高质量论文配图生成脚本。

- 📚 **[408](https://github.com/ciyuan1234/408)**  
  计算机考研专业课 408 核心考点梳理与算法演练库。沉淀高频常考知识点、算法手撕记录与错题深度复盘。

- 🌐 **[Kite-Blog](https://github.com/ciyuan1234/Kite-Blog)**  
  基于 Astro 极速现代框架与 TailwindCSS 构建的个人极客小站。记录底层原理探索、算法推导实录与日常工程踩坑。
